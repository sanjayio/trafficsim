Contribute

TrafficSim is made in the open. There are a few ways to help.

Report a bug

Say what you did, what you expected and what happened. A saved map file (☰ → Save map) helps a lot.

Suggest a feature

Open an issue with the idea and why you'd want it. Check the existing issues first.

Star it on GitHub

It helps other people find the project.

Buy me a coffee

TrafficSim is free and has no ads. Tips on Ko-fi keep it going.

Working on the code

You need Node.js and pnpm. Then:

git clone https://github.com/sanjayio/trafficsim.git
cd trafficsim
pnpm install
pnpm dev     # the game at http://localhost:1420/play/
pnpm test    # simulation tests

How the code is organised:

  • src/core: the simulation and data (road graph, routing, cars). Plain TypeScript, no rendering.
  • src/render: the three.js world, camera and input.
  • src/tools: the build tools, which turn clicks into road and building edits.
  • src/ui: the React menus and panels over the game.
  • src-tauri: the desktop app shell.

For anything bigger than a small fix, open an issue first so we can agree on the approach. Keep pull requests focused, and add a test when you change how cars behave.
